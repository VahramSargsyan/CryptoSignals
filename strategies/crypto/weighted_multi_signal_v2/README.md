## Why V2 exists

V1 historical diagnostics showed that roughly three quarters of its trades were generated by one repeated entry pattern:

`MACD + StochRSI + Volume/Candle`

The other V1 entry combinations were negative in aggregate. That finding is post-hoc, so V2 is a **new candidate**, not a patch to V1.

V1 remains frozen and unchanged.

## Frozen V2 decision rule

An actionable signal requires all three core confirmations on the same completed daily candle.

### BUY

1. MACD > MACD signal line;
2. StochRSI K > D;
3. volume > volume MA20;
4. candle body strength >= 0.50;
5. close > open.

### SELL

1. MACD < MACD signal line;
2. StochRSI K < D;
3. volume > volume MA20;
4. candle body strength >= 0.50;
5. close < open.

SELL retains the current `LONG_ONLY_SIGNAL_FLIP_V1` meaning: it closes a long position; it does not open a short.

## MA50 / MA100 / MA200 role

Moving averages are retained as **context**, not an entry gate.

For BUY, aligned MA context means:

- SMA50 > SMA100 > SMA200;
- close > SMA200.

For SELL, aligned MA context means:

- SMA50 < SMA100 < SMA200;
- close < SMA200.

The MA context does not create or suppress a V2 trade.

Strength:

- core confirmation + MA aligned = 100;
- core confirmation without MA alignment = 80.

This lets the laboratory collect MA context without assuming that the V1 MA vote was causally harmful.

## Bollinger role

Bollinger is not used in the V2 decision rule.

The V1 diagnostic did not provide enough evidence to justify a Bollinger vote inside this momentum/participation candidate. Bollinger can remain a separate mean-reversion research family.
